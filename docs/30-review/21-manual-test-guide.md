## 0. 先澄清：现在**没有"服务"可跑**

架构稿里的 `finance-router` 是**长驻进程**（订阅审批事件 → 自动触发 → outbox 投递）。
**它还没做。** 现在是一组**手动命令**，按顺序跑。

| 现状 | 说明 |
|---|---|
| ✅ 可以手动跑通整条链路 | 见 §2 |
| ❌ 没有常驻服务 | 不会自动感知新提交的审批 |
| ❌ 没有定时任务 | 不会自动催办、自动归档 |
| ❌ 没有事件订阅 | `subscribe.approval` 仍是 `false` |

## 2. 一键跑完整链路

```bash
cd finance-router
bash scripts/pipeline.sh 5
```

它按顺序做 5 件事：

```
1/5 权限体检        doctor
2/5 初始化本地库     db -init
3/5 抽取 N 个实例    extract（下载 → PDF转PNG → 识别 → 入库）
4/5 落到多维表格     sync
5/5 通知需人工的行   notify
```

跑完会打印两条表格链接和后续的人工步骤。

### 2.1 想看"首次入库"的效果

```bash
bash scripts/pipeline.sh 5 --reset   # 先清空本地库（飞书里的数据不动）
```

不加 `--reset` 时会看到**重复拦截**，这是**正确行为**（同一张图已经入过库）：

```
⛔ 重复报销拦截：该图已存在（sha256=5912ae772481…，首次来自实例 C5489DC9-…）
完成：入库 0 单，重复拦截 3 单
```

## 3. 跑完在飞书里看什么

**源表**：<https://<TENANT>.feishu.cn/base/<BITABLE_APP_TOKEN>?table=<TABLE_SUBMISSION>>

| 列 | 看什么 |
|---|---|
| **核对结果** | `一致` / `存疑` / `缺件` —— **决定你要不要细看** |
| **差异说明** | 一句话说明三单金额，或差异原因（人话，无技术细节） |
| **图读金额(元)** / **图读税额(元)** / **图读日期** / **销方名称** | 机器从图里读出的值 |
| **发票文件 / 订单截图 / 付款截图** | **附件，可直接点开看图** |
| **申请编号** | 超链接，点开直达审批原单 |
| 人工审核 / 审核备注 | **只有这两列由人填** |

### 3.1 图片为什么是附件而不是超链接

实测过：审批附件的下载链接**只有 24 小时有效期**，
生产表那种 `previewAttachment?key=` 是**服务端签名的二进制 blob，我们造不出来**。
所以用**附件字段**（长期有效、可内联预览）。

## 4. 三个可以手动验证的场景

### 4.1 防重复报销（数据库级）

```bash
# 第一次
bash scripts/pipeline.sh 2 --reset
#   完成：入库 2 单，重复拦截 0 单

# 第二次（同一批）
bash scripts/pipeline.sh 2
#   ⛔ 重复报销拦截：…（2 条）
#   完成：入库 0 单，重复拦截 2 单
```

**期望**：第二次全部被拦，且本地库**不增长**（事务回滚）。

也可以直接查某张图：

```bash
go run ./cmd/db -dup <sha256>
```

### 4.2 低置信度通知

让某行变成"需人工"，然后跑 `notify`：

1. 在源表里把某行的 **核对结果** 改成 `存疑`
2. `go run ./cmd/notify`
3. **你的飞书应该收到一条消息**（含实例号、槽位、金额、原因）
4. 再跑一次 `notify` → 应显示"已通知过，跳过"（防重复轰炸）

### 4.3 人工审核 → 归档

1. 在源表里把某行 **人工审核** 改成 `通过`
2. `go run ./cmd/archive`
3. **整合表**应出现该行：

<https://<TENANT>.feishu.cn/base/<BITABLE_APP_TOKEN>?table=<TABLE_INTEGRATED>>

4. 再跑一次 `archive` → 应显示"没有待归档"（幂等）

## 5. 出问题时先跑体检

```bash
go run ./cmd/doctor -wiki-token <WIKI_NODE_TOKEN>
```

它会按**错误码**区分不同层的权限问题：

| 错误码 | 含义 |
|---|---|
| `99991672` | scope 没开通（错误里带申请链接） |
| `91403` | scope 有，但**文档级**权限不足 |
| `40004` | 通讯录**数据范围**不覆盖 |
| 响应无 `name` | **字段级**权限不足 |
| `230006` | **机器人能力**未启用 |
| `99992361` | open_id **跨应用**，改用 user_id |
